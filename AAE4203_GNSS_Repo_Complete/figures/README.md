# AAE4203 GNSS Figures — Complete Pack

This archive consolidates the distinct PNG figures found in the project output folders.

## Contents
- 01_satellite_observations: satellite visibility, skyplot, SNR, epoch count, sample epoch table
- 02_spp_diagnostics: GPS SPP clock bias, ECEF changes, position norm, horizontal scatter
- 03_python_vs_rtklib: Python SPP vs RTKLIB component and horizontal differences
- 04_urbannav_v1_v4: UrbanNav V1–V4 availability and trajectory continuity
- 05_spp_comparison_additional: ENU differences, scatter, 3D magnitude, satellite count comparison
- 06_nav_comparison_additional: additional NAV comparison zoomed scatter
- 07_urbannav_benchmark: UrbanNav benchmark observation, ENU, scatter and solution-jump figures

Only byte-identical duplicates are excluded from the image folders. The manifest records these duplicate source aliases, including G16 ablation figures that are identical to the UrbanNav V1–V4 figures.

Raw JPEG screenshots/photos are intentionally not included: they are source/evidence images, not generated report figures.
